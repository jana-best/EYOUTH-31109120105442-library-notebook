QUESTION 1:
How much is each member borrowing?

SQL:
SELECT
    m.member_id,
    m.first_name,
    m.last_name,
    COUNT(c.checkout_id) AS checkout_count
FROM members AS m
LEFT JOIN checkouts AS c
    ON m.member_id = c.member_id
GROUP BY
    m.member_id,
    m.first_name,
    m.last_name
ORDER BY m.member_id;

WHY / WHAT THE CODE DOES:

This query shows how many books each member has borrowed.

It joins the members table with the checkouts table using member_id. COUNT(checkout_id) counts the checkouts for each member.

LEFT JOIN is used so members who have not borrowed any books are still included. Their checkout count will be 0.

The results are grouped by member and ordered by member ID.

QUESTION 2:
Which books match a chosen author pattern?


Chosen pattern: Author starts with A.

SQL:

SELECT
book_id,
title,
author
FROM books
WHERE author LIKE 'A%'
ORDER BY author, title;

WHY / WHAT THE CODE DOES:

This query finds books written by authors whose names start with the letter A.

LIKE 'A%' means that the author's name starts with A.

The query returns the book ID, title, and author.

The results are ordered by author name and then title.

QUESTION 3:
What are the most popular books?


SQL:

SELECT
b.book_id,
b.title,
COUNT(c.checkout_id) AS checkout_count
FROM books AS b
JOIN checkouts AS c
ON b.book_id = c.book_id
GROUP BY
b.book_id,
b.title
ORDER BY checkout_count DESC
LIMIT 5;

WHY / WHAT THE CODE DOES:

This query finds the books with the highest number of checkouts.

It joins books with checkouts using book_id and counts the checkouts for each book.

The results are sorted from the highest count to the lowest. LIMIT 5 keeps only the five most borrowed books.

QUESTION 5:
What does a neighborhood's activity look like further back in time?


Chosen neighborhood: Maadi.
The latest 10 checkouts are skipped.

SQL:

SELECT
m.member_id,
m.first_name,
m.last_name,
m.neighborhood,
c.checkout_id,
c.book_id,
c.checkout_date
FROM members AS m
JOIN checkouts AS c
ON m.member_id = c.member_id
WHERE LOWER(TRIM(m.neighborhood)) = 'maadi'
ORDER BY c.checkout_date DESC, c.checkout_id DESC
LIMIT 10 OFFSET 10;

WHY / WHAT THE CODE DOES:

This query looks at checkout activity for members from the Maadi neighborhood.

It joins checkouts with members using member_id so the neighborhood can be used.

The checkouts are sorted from newest to oldest. OFFSET 10 skips the 10 most recent checkouts.

checkout_id is also used in the ORDER BY so records with the same date have a fixed order.

WEB PAGE VS DATABASE
==================================================

A database stores data in a structured way, so we can use SQL to ask questions and get the records we need.

The Reading Kickoff data is on an HTML web page. It is made for people to read, so the data is inside an HTML table and has to be extracted before we can use it.

A database is already organized into tables and relationships, while a web page presents information for a person to read. This means the web page needs an extra step to turn the displayed table into data that Python can work with.

This difference mattered in this project because the Reading Kickoff checkouts were on a web page instead of being stored in the library database. We needed to extract the table and make its columns match the other checkout data before combining the three sources.
